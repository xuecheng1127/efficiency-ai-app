# 工作台模块（P1）

用户可创建无限独立分区，独立命名/图标，三种模式，数据以 JSON 动态存储。

## 三种模式
1. **任务模式**：完全复用模块1 任务能力（复用 TaskRepository/Provider，勿复制代码）
2. **表格模式**：轻量类 Excel，行列数/行高/列宽/间距滑动条调节 + 左侧实时预览；单元格类型：文本、勾选框
3. **笔记模式**：纯文本碎片化备忘

## 内置模板（一键创建）
采购清单 / 工作待办 / 读书记录 / 观影清单
